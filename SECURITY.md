# Security Policy

## Supported Versions

LiquidKit is pre-1.0. Security fixes are applied to the latest released version
on the `main` branch. Please always upgrade to the latest release before
reporting.

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, report privately using GitHub's
[Report a vulnerability](https://github.com/hamidrezazargham/liquidkit/security/advisories/new)
feature (Security → Advisories), or email the maintainer directly.

Please include:

- A description of the vulnerability and its impact
- Steps to reproduce (a minimal repro is ideal)
- Any suggested remediation

You can expect an initial acknowledgement within a few days. Once confirmed, we
will work on a fix and coordinate a disclosure timeline with you.

Thank you for helping keep LiquidKit and its users safe.
